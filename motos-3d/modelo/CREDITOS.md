## Cambios hechos para Motos 3D

`r3.glb` no es el archivo original. Se giró, se juntaron las 167 mallas en 70 piezas con nombre, se cortaron el lateral, el panel superior y el colín en piezas separadas, se quitaron las texturas, se pusieron materiales nuevos, se simplificaron las piezas pequeñas y se comprimió. El script que hace todo eso está en `../herramientas/r3-construir.mjs`.
